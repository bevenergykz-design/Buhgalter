# Размещение сайта на PS.kz

## Какой тариф нужен

Сайт работает на **Node.js 22**. Обычный виртуальный хостинг PS.kz (панель Plesk) рассчитан на PHP: Node.js в описании тарифа нет, SSH там не даётся. Поэтому нужен **VPS** (раздел «Хостинг → VPS») с root-доступом.

- ОС: **Ubuntu 22.04 LTS** (подойдут и Debian 11/12).
- Ресурсов хватит минимальных: 1 vCPU, 1–2 ГБ RAM, 15–20 ГБ диска. Место на диске нужно в основном под документы клиентов.
- Панель ispmanager/Plesk для VPS покупать не нужно, всё ставит скрипт.
- Включите резервное копирование VPS у PS.kz, если оно предлагается. У сайта есть свои копии в панели, но они лежат на том же диске.

Если заказчик уже оплатил виртуальный хостинг, спросите в поддержке PS.kz, можно ли включить на нём Node.js 22.13 или новее и дать SSH. Если нет, понадобится VPS.

## 1. Домен

В DNS домена создайте две A-записи на IP VPS: `домен.kz` и `www.домен.kz`. Если домен куплен на PS.kz, это делается в личном кабинете PS.kz → «Домены» → DNS. Записи начинают работать через время от нескольких минут до нескольких часов.

## 2. Установка (один раз)

Подключитесь к VPS по SSH под root. Данные доступа PS.kz присылает после создания сервера.

```bash
apt-get update && apt-get install -y git
git clone https://github.com/bevenergykz-design/Buhgalter.git /tmp/dialog && cd /tmp/dialog
```

Если репозиторий закрытый и `git clone` по https просит пароль, скопируйте на сервер один файл `deploy/setup-vps.sh` (например, через `scp`) и запускайте его. Скрипт сам выдаст ключ доступа (deploy key) для GitHub.

```bash
DOMAIN=домен.kz REPO=git@github.com:bevenergykz-design/Buhgalter.git ADMIN_EMAIL=почта-администратора bash deploy/setup-vps.sh
```

Что сделает скрипт:

1. Установит Node.js 22, Nginx и Certbot.
2. Для закрытого репозитория покажет ключ. Его нужно добавить в GitHub → репозиторий → Settings → Deploy keys (только чтение), затем нажать Enter.
3. Скачает сайт в `/srv/dialog-uchet/app`, а данные будет хранить в `/srv/dialog-uchet/data`.
4. Запустит сайт как службу `dialog-uchet`. Служба стартует сама после перезагрузки сервера.
5. Настроит Nginx и выпустит бесплатный сертификат HTTPS Let's Encrypt, который будет продлеваться автоматически.
6. Покажет e-mail и пароль первого входа в панель `/admin`.

## 3. После установки

1. Войдите в `https://домен.kz/admin`. Смените пароль: имя в правом верхнем углу → смена пароля. Затем удалите файл: `rm /srv/dialog-uchet/data/FIRST-ADMIN.txt`.
2. Откройте «Уведомления и интеграции» и заполните:
   - адрес сайта `https://домен.kz`;
   - e-mail для заявок;
   - SMTP. Можно взять почту на домене, если она есть на PS.kz, или Яндекс 360 / Google Workspace. После этого нажмите «Отправить тестовое письмо»;
   - Google Analytics и Search Console.
3. В «Калькуляторе» поставьте реальные цены, в «Контактах» — e-mail и соцсети.
4. Добавьте сотрудников в разделе «Сотрудники».
5. Отправьте с сайта тестовую заявку и зарегистрируйте тестового клиента. Проверьте, что всё дошло, а потом удалите тестовые записи.

## Обновление сайта

После каждого изменения, отправленного в GitHub:

```bash
bash /srv/dialog-uchet/app/deploy/update.sh
```

Данные (`/srv/dialog-uchet/data`) при обновлении не затрагиваются.

## Полезные команды

| Задача | Команда |
|---|---|
| Состояние сайта | `systemctl status dialog-uchet` |
| Журнал ошибок | `journalctl -u dialog-uchet -n 100 --no-pager` |
| Перезапуск | `systemctl restart dialog-uchet` |
| Новый пароль администратора | `cd /srv/dialog-uchet/app && sudo -u dialog env $(cat /etc/dialog-uchet.env) node scripts/create-admin.js почта "Имя"` |
| Скопировать данные на свой компьютер | `scp -r root@IP:/srv/dialog-uchet/data ./backup-dialog` |

## Перенос на другой сервер

На новом сервере запустите `setup-vps.sh`, остановите службу (`systemctl stop dialog-uchet`), замените папку `/srv/dialog-uchet/data` копией со старого сервера или содержимым архива из «Резервные копии» и запустите службу снова.
